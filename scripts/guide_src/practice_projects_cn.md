# 实践项目：按难度组织与评价方式

> 本库只下载、未运行任何案例代码；下列项目基于资料自带的数据/代码说明设计。数据来源、许可证、规模与可复现条件见 catalog 对应列。独立大型数据集（如 CPS/ACS 微观数据、NHANES XPT 文件）本轮未下载，需要时按案例说明自行获取。

## 统一评价量表（每个项目都按此自评/互评）
| 维度 | 要求 |
|---|---|
| 问题与估计目标 | 明确研究问题与 estimand（总体、处理、结局、汇总量） |
| 数据 | 来源、获取方式、许可证、缺失与测量问题 |
| 假设 | 列出并说明可检验与不可检验的假设 |
| 方法 | 与问题匹配，给出替代方法对比 |
| 诊断 | 残差/后验预测/收敛/平衡性等诊断 |
| 不确定性 | 区间或后验，说明其解释 |
| 敏感性 | 至少一项关键假设的敏感性分析 |
| 可复现 | 代码、环境锁定（renv/conda）、一键重跑报告（Quarto） |

## 入门（本科二、三年级）
1. **模拟检验大数定律与中心极限定理**：用〔D03-03〕演示理解，再用 R/Python 自行模拟不同分布下样本均值的收敛速度；参考〔B03-02〕。
2. **回归诊断练习**：〔D09-01〕（CMU 36-401 作业与数据），按评价量表写报告。
3. **NIST 工业案例复现**：〔E3-02〕或〔E3-03〕（实验设计与方差分析），对照手册〔B17-01〕。
4. **Carpentries 完整小项目**：〔D19-01〕或〔D19-02〕。

## 中级（本科高年级—硕士）
1. **估计与检验方法比较的模拟研究**：按 ADEMP 框架（见课程群 20 论文，示例代码〔D20-02〕）比较两种置信区间的覆盖率。
2. **贝叶斯层级模型**：〔E4-04〕（多层回归）或〔E5-03〕（MRP），配合〔B11-02〕、〔S03-01〕，完成后验预测检验。
3. **时间序列预测**：〔B13-01〕+〔D13-02〕，与〔E3-04〕（过程时间序列）对照，做滚动预测评估。
4. **调查数据分析**：〔E5-01〕（NHANES 教程）+ survey 包〔S04-05〕，正确使用抽样权重。
5. **生存与纵向数据**：〔A15-03〕/〔A15-02〕讲义 + survival〔S04-03〕/lme4〔S04-01〕。

## 高级（硕士—博士）
1. **准实验政策评估**：断点回归〔E6-01〕/〔E6-02〕、合成控制〔E6-03〕；要求做带宽/捐赠池敏感性分析。
2. **因果推断完整流程**：〔E1-03〕或〔E6-04〕（随机试验中的工具变量/模型化推断），对照〔B14-04〕。
3. **传染病传播模型的贝叶斯工作流**：〔E1-01〕，参照〔B11-03〕完成先验预测、拟合、诊断、模型比较。
4. **环境水文趋势分析**：〔E4-01〕+〔E4-02〕（EGRET），做季节调整趋势与不确定性评估。
5. **保险损失曲线/金融即时预测**：〔E2-03〕或〔E2-02〕。
6. **论文复现**：从课程群 13–17 论文中选一篇带公开代码的方法论文，按评价量表做复现报告与扩展（注意：本库只做了下载核验，未验证可复现性）。
